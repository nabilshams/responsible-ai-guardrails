Enterprises increasingly use text, documents, images, and operational data with AI. This content can contain personal information or credentials that should not enter an AI workflow unintentionally.

Sensitive Data Protection creates redacted copies for review before content is used with AI, indexed for search, or shared with others.

The text workflow detects supported personal information and runtime credentials. It returns a redacted copy without displaying the original content in the activity history.

Documents can be processed while preserving their usable native format. The resulting redacted copy can be reviewed before it is used by an AI application or shared with another party.

For images, text is located using optical character recognition, and pixels containing detected personal information are masked in the returned copy.

This accelerator complements Microsoft services such as Azure AI Language, Azure Document Intelligence, Microsoft Foundry, Microsoft Purview, and Azure API Management. It does not replace those services. It turns their capabilities into an application-ready privacy workflow.

Automated detection can miss sensitive information. Always review the redacted copy before using it with AI, indexing it for search, or sharing it with others. Protect sensitive information before it enters your enterprise AI workflow.
